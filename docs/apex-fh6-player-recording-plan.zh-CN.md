# Apex Tune Hub FH6 新手实测与录制计划

这个文件是给你本人用的中文执行清单。目标不是让你变成高手，而是让你稳定采集 Apex Tune Hub 需要的原创游戏素材：视频、截图、路线、车辆、问题症状、调校前后对比。以后我可以基于这些素材写攻略文章，并在文章里标注“来源：Apex Tune Hub 原创游戏录制”。

## 核心目标

先证明网站核心功能真的有用：

1. 玩家遇到一个车的问题，比如转向不足、打滑、起步慢、尾速不够。
2. 打开 Apex Tune Hub 的调校计算器。
3. 生成一个基础调校方向。
4. 回到游戏跑两次对比。
5. 截图和录屏证明“改了什么、怎么测试、结果如何”。

你不用一开始就玩很远，也不用完美跑圈。我们要的是可复现的真实过程。

## 先玩到哪里

因为游戏版本和解锁流程可能会变，先不要追求固定章节名称。你只需要玩到满足下面条件为止：

1. 能自由进入车库或车辆菜单。
2. 能看到车辆等级、驱动形式、轮胎、升级或调校设置。
3. 能选择一个路线、赛事、测速点、漂移区，或者至少能在开放世界稳定跑一段路。
4. 能重复同一段路线至少两次。

如果游戏有序章、开场教学、新手赛事、嘉年华开场，就先把这些做完，直到你可以自由开车、换车、进车库、打开调校菜单。到了这个阶段就可以开始录制，不需要先通关。

## 第一次只选一种车

第一批素材只需要一辆容易获得的车。优先顺序：

1. 游戏开局送的车。
2. 新手赛事奖励车。
3. 你已经能稳定驾驶的 AWD 或 RWD 街车。
4. 不要一开始选特别快、特别难控、特别贵的车。

记录这几个信息：

| 项目 | 示例 |
| --- | --- |
| 车辆 | 202x Starter Car |
| 等级 | A / S1 / S2 |
| 驱动 | AWD / RWD / FWD |
| 轮胎 | Street / Sport / Race / Drift |
| 控制方式 | 键盘 / 手柄 / 方向盘 |
| 辅助设置 | ABS、TCS、STM、自动挡或手动挡 |

## 录屏设置

### Windows Game Bar

最简单的方法：

1. 按 `Win + G` 打开 Xbox Game Bar。
2. 按 `Win + Alt + R` 开始或停止录制。
3. 录制 1080p，30fps 或 60fps 都可以。
4. 可以录游戏声音，不需要开麦克风。
5. 每段视频控制在 3 到 5 分钟，不要录一整小时。

### OBS 可选

如果你已经会用 OBS，可以用 OBS。但第一阶段不强求，Windows Game Bar 就够。

推荐设置：

| 设置 | 建议 |
| --- | --- |
| 分辨率 | 1920x1080 |
| 帧率 | 30fps 或 60fps |
| 码率 | 8000 到 12000 Kbps |
| 音频 | 游戏声音即可 |
| 麦克风 | 可关 |

## 每次必须截图什么

每次 45 分钟实测至少截图这些：

1. 车辆页面：车名、等级、驱动形式。
2. 路线或赛事页面：路线名、地图位置、赛事类型。
3. 调校前设置：关键设置页面。
4. 调校后设置：改过的设置页面。
5. 结果页面：时间、分数、名次、失败或成功提示。
6. 问题瞬间：比如入弯推头、出弯打滑、换挡太早、尾速上不去。

截图不需要很美，重点是信息完整。

## 第 1 次 45 分钟实测：通用调校计算器

目标：验证首页和 Tune Calculator 是否真的能帮新手解决一个车感问题。

时间安排：

| 时间 | 操作 |
| --- | --- |
| 0-5 分钟 | 打开游戏，选一辆车，截图车辆页面 |
| 5-10 分钟 | 找一段可以重复跑的路线或赛事，截图路线 |
| 10-15 分钟 | 不改设置，跑一次 baseline，录 3-5 分钟 |
| 15-20 分钟 | 写下最明显的问题：推头、甩尾、刹不住、起步慢 |
| 20-25 分钟 | 打开 `https://apextunehub.com/tools/forza-horizon-6-tune-calculator`，按症状生成调校方向 |
| 25-30 分钟 | 回游戏改 1 到 3 个关键设置，截图改前改后 |
| 30-40 分钟 | 跑两次同一路线，录第二段和第三段 |
| 40-45 分钟 | 截图结果，记录是否更好、更差、没感觉 |

记录模板：

## 第 2 次 45 分钟实测：齿比计算器

目标：验证 Gear Ratio Calculator 对起步、换挡、尾速的帮助。

你要找一段适合测试加速的地方：

1. 一条比较直的路。
2. 一个可以重复起步的位置。
3. 最好有明显的测速点、冲刺赛、直线路段，或者能看最高速度的地方。

重点观察：

| 现象 | 可能记录 |
| --- | --- |
| 起步太肉 | 低速档可能太长 |
| 一直撞转速红线 | 齿比可能太短 |
| 最高速度上不去 | 高速档可能太短或动力不足 |
| 换挡后掉速严重 | 档位间距可能太大 |

录制流程：

1. 截图当前齿比页面。
2. 从同一个位置起步，录 baseline。
3. 打开 `https://apextunehub.com/tools/forza-horizon-6-gear-ratio-calculator`。
4. 只改最终传动比或少数档位，不要一次大改全部。
5. 再跑两次同一路段。
6. 截图最高速度、成绩或体感结果。

## 第 3 次 45 分钟实测：漂移调校计算器

目标：验证 Drift Tune Calculator 对入弯、维持角度、出弯回正的帮助。

你要找：

1. 一个漂移区。
2. 一个空旷弯道。
3. 或者一个能反复练同一组弯的开放道路。

重点观察：

| 现象 | 可能记录 |
| --- | --- |
| 入弯不愿意转 | 前端抓地或刹车/差速方向需要检查 |
| 一给油就转过头 | 后轮太容易失控 |
| 角度维持不住 | 动力、差速、悬挂需要分组测试 |
| 出弯回不来 | 方向、差速、轮胎压力可能要调整 |

录制流程：

1. 录一段原始漂移尝试，不要管分数。
2. 截图漂移设置。
3. 打开 `https://apextunehub.com/tools/forza-horizon-6-drift-tune-calculator`。
4. 只改一组设置。
5. 再录两段同一地点尝试。
6. 截图分数或最明显的问题瞬间。

## 第 4 次 45 分钟实测：转向过度/转向不足攻略页

目标：给高点击攻略页补真实素材。

优先页面：

```text
https://apextunehub.com/games/forza-horizon-6/guides/fix-oversteer
```

可以补充的素材：

1. 入弯甩尾视频。
2. 出弯给油甩尾视频。
3. 改设置前后的对比截图。
4. 同一路线两次结果对比。

如果你能录到“问题很明显”的片段，比录到完美成绩更有价值。

## 不要做什么

1. 不要把别人的 YouTube 视频截图当成我们自己的截图。
2. 不要录到账号、邮箱、支付、聊天、好友列表等个人信息。
3. 不要一边录一边频繁切出游戏到隐私页面。
4. 不要为了一个结果改十几个设置，那样文章很难解释。
5. 不要写“这是最终最强调校”，除非我们有足够实测。
6. 不要追求完美圈速。第一阶段只要能说明问题。

## 第一批素材优先级

按这个顺序录：

1. Tune Calculator：转向不足或转向过度。
2. Gear Ratio Calculator：起步、换挡、尾速。
3. Drift Tune Calculator：入弯、维持角度、出弯。
4. `fix-oversteer` 攻略页：真实问题截图和视频。
5. 首页核心工作台：从首页进入工具的完整流程。

只要你每周完成 2 到 3 次 45 分钟实测，我们就可以持续产出更像真实玩家写出来的内容，而不是空洞文章。
